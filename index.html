KobraOS

Open-source AI companion for the Anycubic Kobra X
KobraOS transforms the Anycubic Kobra X into a smarter, locally controlled 3D printer. Built around ESP32, it delivers real-time printer monitoring, local MQTT communication, voice interaction, AI assistance and future Home Assistant integration — all without depending on cloud services.
View on GitHub Documentation

Current Features

Local Control

No cloud dependency. Everything runs on your local network.

Automatic Discovery

Automatically detects compatible printers on your LAN.

Live Monitoring

Real-time temperatures, progress, layers and printer status.

Secure MQTT

Encrypted local communication without external servers.

ESP32 Powered

Designed around the ESP32-S3 platform for speed and flexibility.

Open Source

Built by the community and open to contributors.
